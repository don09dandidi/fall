# 🚴 Bicycle System – Handout 2

## Overview
This project implements a simple **Object-Oriented system** in **Python**, based on the *Bicycle* concept from Handout 1.

It simulates:
- a `Rider` starting a `Trip` using a `Bicycle`,
- performing actions like pedaling, braking, and changing gears,
- tracking distance and trip duration.

## 🧱 System Components

| Class | Description |
|-------|--------------|
| **Bicycle** | Represents a bike with speed, gears, and actions. |
| **Rider** | Represents a cyclist who can start/end trips and track total distance. |
| **Trip** | Represents a single ride session, storing time and distance. |
